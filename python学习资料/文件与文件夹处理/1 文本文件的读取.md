## 1 文本文件的读取

read([size]) ：读取指定size个字符数，为给定size将文本文件所有行读到一个字符串中。

readline() ：是一行一行的读，每次调用读一行

readlines() ：是将文本文件中所有行读到一个list中，文本文件每一行是list的一个元素。

### 1.2 readline()


### 1.3 readlines()

readlines方法和readline方法长得像，但功能不一样，前面说过readline方法只读取一行，readlines方法则是读取所有行，返回的是所有行组成的列表。readlines方法没有参数，使用更加简单。依旧以wenjian1为例：

```python
with open('wenjian1.txt','r') as f :
    a = f.readlines()
    print(a)
#['苔\n', '袁枚\n', '白日不到处\n', '青春恰自来\n', '苔花如米小\n', '也学牡丹开']
```

从以上可以看出，readlines()返回一个列表因此可以使用for迭代每行内容。

```python
with open('wenjian1.txt','r') as f :
    a = f.readlines()
    for i in a:
        print(i,end='')
#苔
#袁枚
#白日不到处
#青春恰自来
#苔花如米小
#也学牡丹开
```

## 2 文本文件指针的定位

seek的标准形式为 :seek(offset[,whence])

whence 默认值为0，表示从文件开头进行计算偏移量，这时候offset必须大于等于0
whence 如果为1，表示从当前位置开始计算偏移量，如果offence为负数，表示往前移动，为正表示往后移动
whence 如果为2，表示相对于文件末尾移动

```python
with open('file3.txt','r') as f :

    print(f.seek(3))
    f.read(1)
    print(f.seek(-3, 2))  #报错
#3
#Traceback (most recent call last):
#  File "E:\科师\2021春资料\课程\python\ces\text1.py", line 5, in <module>
#    print(f.seek(-3, 2))  #报错
#io.UnsupportedOperation: can't do nonzero end-relative seeks
```

**因为Pyhon3在文本文件中，没有使用b模式选项打开的文件，只允许从文件头开始计算相对位置，从文件尾计算时就会引发异常**

解决方法在开始使用open打开文件时候，将打开方式从r，换成rb即可

```python
with open('file3.txt','rb') as f :

    print(f.seek(3))
    f.read(1)
    print(f.seek(-3, 2))  
#3
#6
```

```python
with open('file3.txt','rb') as f :

    print(f.seek(0))
    print(f.read())
    print(f.seek(0, 2))
    print(f.read())
    print(f.seek(-1, 2))
    print(f.read())
#0
#b'123456789'
#9
#b''
#8
#b'9'
```

观察可以发现，指针处的位置进行r+不会覆盖所有内容，而是替换。\n为2个字符数。
