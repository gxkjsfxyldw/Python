# 正则表达式的模式匹配

## 1 边界匹配

| 边界符 | 描述                           |
| ------ | ------------------------------ |
| ^      | 匹配字符串的开头或者一行的开头 |
| $      | 匹配字符串的结尾或者一行的结尾 |
| \b     | 匹配单词头或单词尾             |
| \B     | 与\b含义相反                   |

```
1）最简单的正则表达式是普通字符串，只能匹配自身，如'abc'，只能匹配'abc'。
2）'a.c'可以匹配'abc'、'acc'、'adc'等，.可匹配任何单字符。
3）'abc*'可以匹配'ab'、'abc'、'abcc'等字符串，*用于匹配位于*之前的字符0次或多次。
4）'abc+'可以匹配'abc'、'abcc'、'abccc'等字符串，+用于匹配位于+之前的字符1次或多次。
5）'abc? '可以匹配'ab'和'abc'字符串，?用于匹配位于?之前的字符0次或1次。
6）'ab{2}c'可以匹配'abbc'，{2}匹配{2}之前的字符2次。
7）'ab{1, 2}c'，可完整匹配的字符串有2个：'abc'、'abbc'
8）'^asddg'可以匹配行首以'asddg'开头的字符串。
9）'rld$'可以匹配行尾以'rld'结束字符串。
10）'abc|xyz'可以匹配'abc'和'xyz'，|用于匹配位于|之前或之后的字符。
11）'(abc){2}'可以匹配'abcabc'，{2}匹配{2}之前的表达式(abc)2次。
12）'a(123|456)b'可以匹配'a123b'和'a456b'。

```

# 2 分组

分组就是用一对圆括号“()”括起来的正则表达式，匹配出的内容就表示一个分组。从正则表达式的左边开始看，看到的第一个左括号“(”表示第一个分组，第二个表示第二个分组，依次类推，需要注意的是，有一个隐含的全局分组（就是0），就是整个正则表达式。
分完组以后，要想获得某个分组的内容，直接使用group(num)和groups()函数去直接提取就行。

### 命名分组

在前面学习了分组匹配的模式，可以通过groups()来全部访问匹配的元组，也可以通过group()函数来按分组方式来访问，但是这里只能通过数字索引来访问，如果某一天产品经理需要修改需求，让你在它们之中添加一个分组，这样一来，就会导致匹配的数组的索引的变化，作为开发人员的你，必须得一行一行代码地修改。因此聪明的开发人员又想到一个好方法，把这些分组进行命名，只需要对名称进行访问分组，不通过索引来访问了，就可以避免这个问题。那么怎么样来命名呢？可以采用(?P<name>pattern)的格式来命名。例子如下：

```python
#(?P<name>正则表达式)         #name是一个合法的标识符
import re
s = "'230.192.168.78',version='1.0.0'"
h = re.search("'(?P<ip>\d+\.\d+\.\d+\.\d+).*",s)  #只有一个分组
print(h.group('ip'))
print(h.group(1))
#230.192.168.78
#230.192.168.78

import re
t = 'good better best'
d = re.search('(?P<good>\w+)\s+(?P<better>\w+)\s(?P<best>\w+)',t)
print(d.group('good'))
print(d.group('better'))
print(d.group('best'))
print(d.group(1))
print(d.group(2))
print(d.group(3))
print(d.group())
#good
#better
#best
#good
#better
#best
#good better best
```

## 选择操作

圆括号的另一个重要的表示可选性，根据需要建立支持二选一或多选一的应用，这涉及'()'和'|'两种元字符，'|'表示逻辑或的意思。如'a(123|456)b'可以匹配'a123b'和'a456b'。

查找he和He两个字的正则表达式可以写成(he|He)，还可以写成(h|H)e。

Doctor、doctor、Dr.、Dr可以写成(Doctor|doctor|Dr\\.|Dr)  或者(Doctor|doctor|Dr\\.?)

| 选项 |     描述     |
| :--: | :----------: |
| (?i) | 不区分大小写 |
| (?m) |     多行     |
| (?s) |     单行     |
| (?U) | 默认最短匹配 |

###  （?i）

不区分大小写(?i) 比如he和He可以写成(?i)he

```python
t = 'gOod Good best'
d = re.search('(?i)good',t)
print(d.group())
#gOod
```

## 分组后引用

分组，即分组匹配，也称为捕获组，是正则中的一种比较重要的匹配方式。此外后向引用和分组相结合，可以写出很多复杂匹配场景的正则。(?:)指定了一个非捕获组（即，这个组只做匹配但不捕获结果，也不会分配组号）

### 1.分组

#### 1.1.无序分组

无名分组就是用一对圆括号“()”括起来的正则表达式，匹配出的内容就表示一个分组。

```python
import re
s = 'c1c b2b c3c'
p = re.compile(r'c(\d)c')
print(p.findall(s))
#['1', '3']
```

```python
import re
s = 'age:13,name:Tom;age:18,name:John'
p = re.compile(r'age:(\d+),name:(\w+)')
it = p.finditer(s)
for m in it:
    print('------')
    print(m.group())
    print(m.group(0))
    print(m.group(1))
    print(m.group(2))
#------
#age:13,name:Tom
#age:13,name:Tom
#13
#Tom
#------
#age:18,name:John
#age:18,name:John
#18
#John
```

有时候给正则的某个子表达式加括号并不是为了分组，而仅仅是为了看起来更清晰，因此在匹配结果中并不想匹配该子表达式，那么该怎么办呢？答案是忽略该分组，方法：(?:exp)。举例：只想匹配name，不想匹配age：

```python
import re
s = 'age:13,name:Tom'
p1 = re.compile(r'age:(\d+),name:(\w+)')
# 不忽略分组
print(re.findall(p1, s))

# 忽略分组
p2 = re.compile(r'age:(?:\d+),name:(\w+)')
print(p2.findall(s))

#[('13', 'Tom')]
#['Tom']
```



#### 1.2.有序分组

有序分组就是给分组命名
格式：(?P正则表达式)
引用分组：s.group(“分组名”)

见命名分组

#### 1.3.后向引用

定义：当用“()”定义了一个正则表达式分组后，正则引擎就会把匹配的组按照顺序进行编号，然后存入缓存中。这样我们就可以在后面对已经匹配过的内容进行引用，这就叫后向引用
所谓后向引用，就是对前面出现过的分组再一次引用，使用默认的分组名称进行后向引用：\1,\2,\3…

```python
import re
s = 'hello blue go go hello'
p = re.compile(r'\b(\w+)\b\s+\1\b')  # 这里的'\1'就对应前面的(\w+)
p1 = re.compile(r'\b(\w+)\b\s+(\1\b)')
print(p.findall(s))
print(p1.findall(s))
#['go']
#[('go', 'go')]
```

##### 自定义名称分组的后向引用

python正则可以对分组自定义名称，然后可以使用自定义名称进行后向引用，使用自定义分组名称比使用默认分组名称更加清晰、更容易让人理解。对分组自定义名称的方法：

```
定义名称 (?P<myname>exp)
引用     (?P=myname)
```

```python
import re
s = 'hello blue go go hello'
p = re.compile(r'\b(?P<my_group1>\w+)\b\s+(?P=my_group1)\b')
p1 = re.compile(r'\b(?P<my_group1>\w+)\b\s+((?P=my_group1))\b')
print(p.findall(s))
print(p1.findall(s))
#['go']
#[('go', 'go')]
```

#### 1.4 嵌套分组

```python
s  = '2017-07-10 20:00'
p = re.compile(r'(((\d{4})-\d{2})-\d{2}) (\d{2}):(\d{2})')
print(re.findall(p, s))
se = p.search(s)
print(se.group())
print(se.group(0))
print(se.group(1))
print(se.group(2))
print(se.group(3))
print(se.group(4))
print(se.group(5))
#[('2017-07-10', '2017-07', '2017', '20', '00')]
#2017-07-10 20:00
#2017-07-10 20:00
#2017-07-10
#2017-07
#2017
#20
#00
```
