# 1 模块

## 1.1 什么是模块  （就是不同的py文件）

这里厘清python中模块、库、包之间的概念差异

- 模块(module)其实就是py文件，里面定义了一些函数、类、变量等
- 包(package)是多个模块的聚合体形成的文件夹，里面可以是多个py文件，也可以嵌套文件夹
- 库是参考其他编程语言的说法，是指完成一定功能的代码集合，在python中的形式就是模块和包

## 1.2 模块的创建

首先创建一个文件`myModule.py`如下



```python
#myModule.py
def func():
    print('自定义模块myModule下的自定义函数func()')

class MyClass:
    def myFunc(self):
        print("自定义模块myModule 自定义类myClass 自定义函数myFunc()")
```

然后在同目录下创建一个名字为`call_myModule.py`的文件。

```python
#call_myModule.py
import myModule  //引用其他的文件
myModule.func()	  //引用其他文件中的函数
myclass = myModule.MyClass()//引用其他文件中的类
myclass.myFunc()		//引用其他文件中的类中的函数
#自定义模块myModule下的自定义函数func()
#自定义模块myModule 自定义类myClass 自定义函数myFunc()
```

* 注意两个文件必须在一个目录下

# 2 模块的导入和使用

## 2.1 import 语句

模块定义好后，我们可以使用 import 语句来引入模块，语法如下：

```
import module1[, module2[,... moduleN]]
```

比如要引用模块 math，就可以在文件最开始的地方用 **import math** 来引入。在调用 math 模块中的函数时，必须这样引用：

```
模块名.函数名
```

当解释器遇到 import 语句，如果模块在当前的搜索路径就会被导入。

搜索路径是一个解释器会先进行搜索的所有目录的列表。如想要导入模块myModule.py，需要把命令放在脚本的顶端：

```python
# 导入模块
import myModule
 
# 现在可以调用模块里包含的函数了
myModule.func()
myclass = myModule.MyClass()
myclass.myFunc()
```

## 2.2 from…import 语句

Python 的 from 语句让你从模块中导入一个指定的部分到当前命名空间中。语法如下：

```
from modname import name1[, name2[, ... nameN]]
```

例如，要导入模块myModule的 func 函数，使用如下语句：

```
from myModule import func  //引用此函数到from+这个名称里面 就可以直接调用了这个名称了 but 就单独引用一个函数而已
```

这个声明不会把整个 fib 模块导入到当前的命名空间中，它只会将 myModule里的 func单个引入到执行这个声明的模块的全局符号表。

## 2.3 from…import* 语句

把一个模块的所有内容全都导入到当前的命名空间也是可行的，只需使用如下声明：

```python
from myModule import * //引用此函数到from+这个名称里面 就可以直接调用了这个名称了 but 引用全部的函数
#然后可以使用文件中所有模块
func()
```

这提供了一个简单的方法来导入一个模块中的所有项目。然而这种声明不该被过多地使用。

# 3 模块的主要属性

## 3.1 `__name__`

- `__name__`是一个变量，前后加了双下划线是系统定义的名字
- A模块若是被B模块导入，在B模块中获取A模块"`__name__`"的值就是A模块的名字(即：文件名)
- 若直接执行模块(即：执行.py文件)，`__name__`的值为’__main__’

创建文件名为test

`test.py`

```python
if __name__ == '__main__':  #就是此文件的编译时刻时的名称
    print('该模块被当作脚本直接运行')

elif __name__ == 'test':	#在其他文件被引用时的名称
    print('该模块被导入到其他模块进行使用')
#直接运行后结果如下
#该模块被当作脚本直接运行
```

如果创建一个文件名为call_tset文件

`call_test.py`

```python
import test
#该模块被导入到其他模块进行使用
```



## 3.2 `__all__`

python模块中的__all__，用于模块导入时限制，如：**from module import \***

此时被导入模块若定义了__all__属性，则只有__all__内指定的属性、方法、类可被导入；若没定义，则导入模块内的所有公有属性，方法和类。

创建一个文件名为module1

`module1.py`

```python
class Person:
    def __init__(self,name,age):
        self.name = name
        self.age = age
class Student:
    def __init__(self,name,id):
        self.name = name
        self.id = id
def func1():
    print('func1()被调用')
def func2():
    print('func2被调用')
```

首先不使用`__all__`

然后在创建一个文件名为test_module1来调用这个module

`test_module1`

```python
from module1 import *
person = Person('张三','24')
print(person.name,person.age)
student = Student('李明',1801122)
print(student.name,student.id)
func1()
func2()
```

运行结果

```python
张三 24
李明 1801122
func1()被调用
func2被调用
```

使用`__all__`



创建一个文件名module2

```python
__all__ = ('Person','func1')
class Person:
    def __init__(self,name,age):
        self.name = name
        self.age = age

        self.name = name
        self.id = id
def func1():
    print('func1()被调用')

```

然后创建test_module2文件

`test_module2.py`

```python
from module2 import *
```


## 3.3 查看模块方法

这里介绍下python自带的查看帮助功能，可以在编程时不中断地迅速找到所需模块和函数的使用方法

* help()

进入help帮助文档界面，根据屏幕提示可以继续键入相应关键词进行查询，继续键入`modules`可以列出当前所有安装的模块：

```python
help(sorted) #查看函数和模块用途的详细说明
```

运行结果


* `__doc__`

被编译器存放到 模块、函数、类 的__doc__属性中。不过，并非每一个模块、函数、类都有文档字符串。

* dir()

**dir()** 函数不带参数时，返回当前范围内的变量、方法和定义的类型列表；带参数时，返回参数的属性、方法列表。如果参数包含方法__dir__()，该方法将被调用。如果参数不包含__dir__()，该方法将最大限度地收集参数信息。

```python
import doc1
print(dir()) #  获得当前模块的属性列表
print(dir(doc1))#  获得doc1的属性列表
```
