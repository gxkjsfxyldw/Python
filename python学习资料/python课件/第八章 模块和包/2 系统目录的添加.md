# 1 系统目录的添加

## 1.1 导入模块时搜索目录的顺序

import是按照sys.path变量的值搜索模块的。sys.path包含当前目录、Python安装目录、PYTHONPATH环境变量，一般优先搜索当前目录。

```python
import sys
print(sys.path)
#也可以使用下面方法打印
import sys,pprint
pprint.pprint(sys.path)
```

打印的值，第一个是当前位置，sys中的path对象包含了所有系统目录。

## 1.2 临时添加系统目录

通过append()方法添加系统目录。因为系统目录是存在于sys.path对象下，对象是一个列表，所有可以通过append()方法往其中插入目录。

```python
import sys
sys.path.append('需要添加的路径')
print(sys.path)#查看路径是否添加成功
```

重启解释器时，刚刚添加的路径不存在了。因此此方法是临时添加。

## 1.3 永久添加系统目录

在lib\\site-packages目录下创建xx.pth文件名，在文件中输入所要添加的目录即可。一行写一个路径。
